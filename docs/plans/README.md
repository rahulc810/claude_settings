# Plans

Numbered, append-only design records, written **before** the work. A plan's number is
permanent — never reused, never renumbered, even when abandoned. Status is tracked in the
table below only, never by renaming or deleting a file.

| Status | Means |
|---|---|
| **authored** | written, not started |
| **implemented** | landed — matching `docs/COMPLETE_ACTIONS.md` entry exists |
| **superseded** | replaced — name the successor plan in Notes |
| **abandoned** | dead — say why in Notes |
